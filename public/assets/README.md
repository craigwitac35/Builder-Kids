# Builder Kids — Asset Drop Zone

Drop finished art into these folders using the EXACT filenames from the
execution plan's naming list (all lowercase, kebab-case). The game renders a
labeled placeholder box for any missing file and automatically swaps in the
real image the moment the file exists — no code changes needed.

Folders:
  characters/      helper poses, dog          (512–768px, transparent PNG/WebP)
  props/           tools, boards, nails       (256px, transparent)
  scenes/          project stages, intros     (1920x1080)
  ui/              icons, logo                (128px icons / logo sizes as produced)
  effects/         effect-reward-burst.png    (512px, transparent, static)
  customization/   paint swatches, decos      (256px, transparent)
  blueprints/      blueprint graphics
  collection/      collection-screen-bg.png, collection-locked-slot.png
